# AD01 — ตีสอง กระป๋องนมผง (โฆษณา DODOLOVE กระปุกเก็บนมผง)

```
ถ้าลูกร้องหิวตอนตีสอง อย่าเพิ่งตักนมผงจากกระป๋องที่เปิดไว้ เพราะสิ่งที่ทำให้นมผงเสีย ไม่ใช่วันหมดอายุ แต่คือความชื้น นมผงที่เปิดแล้ว ควรใช้ให้หมดภายในสี่สัปดาห์ คุณพลิกดูก้นกระป๋อง เปิดมาแล้วสิบเก้าวัน ยังอยู่ในกำหนด ตีสองห้านาที ในครัว เจ้าส้มจี๊ดนั่งจ้องกระป๋อง ไม่ยอมขยับ คุณล้างมือ เช็ดให้แห้ง แล้วเปิดฝา ช้อนตวงจมอยู่ในนมผง คุณใช้นิ้วคุ้ยขึ้นมา ตีสองแปดนาที น้ำอุ่นพร้อมแล้ว แต่ผงไม่ยอมละลาย คุณทำถูกทุกอย่าง ยกเว้นเรื่องเดียว ฝากระป๋อง ปิดไม่สนิทมาตั้งแต่เมื่อวาน ความชื้นเข้าไปทั้งคืน นมผงจับเป็นก้อนตั้งแต่ก่อนคุณตื่น กระปุกดูดูเลิฟ ฝาซีลกันชื้น ช้อนแม่เหล็กติดอยู่ที่ฝา ไม่ต้องเอานิ้วคุ้ย หนึ่งร้อยเจ็ดสิบเก้าบาท พิกัดอยู่ในตะกร้า เพราะตีสองคืนพรุ่งนี้ ลูกก็จะร้องอีก
```

ความยาวโดยประมาณ 45–50 วินาที (15 แถว) สั้นกว่าสูตรเดิม 65–72 วินาที เพราะเป็นโฆษณาและเจ้าของกำหนดไม่เกิน 1 นาที

## อธิบายเนื้อเรื่อง

- **เรื่องเกี่ยวกับอะไร**: พ่อหรือแม่ ("คุณ") ตื่นมาชงนมให้ลูกตอนตีสอง ทำทุกขั้นตอนถูกหมด แต่นมผงกลับไม่ละลาย
- **ทำไมมีกฎนี้**: คนส่วนใหญ่เช็กแค่วันหมดอายุ แต่ตัวที่ทำให้นมผงเสียหลังเปิดคือความชื้น กฎ "อย่าเพิ่งตัก" จึงฝืนสัญชาตญาณของคนที่กำลังรีบ
- **สิ่งลี้ลับ**: ไม่มีผี "ตัวร้าย" ของเรื่องคือความชื้นที่มองไม่เห็น
- **สัตว์คู่หู**: แมวส้มชื่อส้มจี๊ด นั่งจ้องกระป๋องก่อนที่คนจะรู้ว่ามีอะไรผิดปกติ
- **จุดหักมุม**: ฝากระป๋องปิดไม่สนิทมาตั้งแต่เมื่อวาน รายละเอียดนี้ต้องเห็นในภาพตั้งแต่แถว 4–5 (ฝาเผยอเอียงข้างหนึ่ง และแมวจ้องตรงจุดนั้น) คนที่ดูซ้ำจะหาเจอ
- **สินค้าเข้ามาตรงไหน**: แถว 12–13 สินค้าเป็นคำตอบของสองปัญหาที่เห็นในเรื่อง (ฝาไม่สนิท และต้องเอานิ้วคุ้ยช้อน) แสดงเป็นโมเดล 3 มิติ แล้วตัดเป็นรูปสินค้าจริงจากร้านในแถว 14
- **ตอนจบ**: แถว 15 ใช้แทนคลิฟแฮงเกอร์ เพราะโฆษณาไม่มีตอนต่อ

## ข้อเท็จจริงกับเรื่องแต่ง

- เรื่องนี้เป็นเรื่องแต่ง
- **ต้องตรวจก่อนผลิต (ยังไม่ได้ตรวจกับแหล่งข้อมูล)**:
  - "ใช้ให้หมดภายในสี่สัปดาห์หลังเปิด" เป็นคำแนะนำที่พบบนฉลากนมผงหลายยี่ห้อ แต่บางยี่ห้อระบุสามสัปดาห์ ต้องเทียบกับฉลากจริง
  - "ความชื้นทำให้นมผงจับเป็นก้อน" ตรงกับคำอธิบายในหน้าสินค้าของร้าน
- **มาจากหน้าสินค้า Shopee**: ฝาซีลกันความชื้น, ช้อนตวงแม่เหล็กติดกับฝา, ราคา 179 บาท (ราคาเปลี่ยนได้ ต้องเช็กวันที่ลง)
- บทไม่ได้พูดว่ากระปุกทำให้นมผงอยู่ได้นานขึ้น หรือดีต่อสุขภาพลูก พูดแค่คุณสมบัติที่ร้านระบุ
