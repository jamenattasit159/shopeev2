## หลัง pull บนเครื่องใหม่ ต้องติดตั้งอะไร

1. `cd story && npm install` (ตัวเรนเดอร์ 3 มิติ) และ `cd render && npm install` (ตัวทำคลิปรีวิวเดิม)
2. `python -m pip install faster-whisper numpy` (จับเวลาเสียง ครั้งแรกจะดาวน์โหลดโมเดล small และ medium)
3. ffmpeg ต้องอยู่ใน PATH
4. คัดลอก `config.example.toml` เป็น `config.toml` แล้วใส่ Gemini API key (ใช้พากย์เสียง)
5. เปิดโปรแกรมด้วย `start.bat` (build ครั้งแรกเอง) แล้วเข้า http://127.0.0.1:4317/story
6. รีโหลดส่วนขยาย Chrome ใน `chrome://extensions` (เวอร์ชัน 0.1.3 ใส่ตัวอ่านหน้าเว็บเองเมื่อกดไอคอนบนแท็บเก่า)

หน้า Story Ad จะขึ้นกล่องเตือนเองถ้ายังขาดอะไร

## สิ่งที่เปลี่ยนวันนี้ (เผื่อดูย้อน)

- เส้นเรื่องไม่ซ้ำ: มีมุมเล่า 6 แบบ (หักมุม, ความเชื่อผิด, นับถอยหลัง, สัญญาณเตือนสามข้อ, สองทางเลือก, สิ่งที่แมวเห็น) ระบบเลือกมุมที่ 3 คลิปล่าสุดยังไม่ใช้ และส่งเรื่องเก่าไปห้าม AI ซ้ำ รายละเอียดอยู่ใน design doc ข้อ 4.1 (`docs/superpowers/specs/2026-11-11-story-ad-design.md`)
- AI ต้องเขียน `productUse` ก่อนแต่ง และมี AI อีกรอบตรวจว่าเรื่องตรงสินค้าและไม่ซ้ำ
- ฉากครัวไม่มีฉลาก "นมผง" ติดตายตัวแล้ว เพิ่มคราบบนเคาน์เตอร์ เขียง เนื้อดิบ
- ถ้าหน้าสินค้าไม่มีราคา AI จะไม่พูดราคา
- จับเวลาเสียง: ลอง Whisper medium อัตโนมัติ แก้ช่วงซ้อน และประมาณเวลาแถวที่หาไม่เจอแทนการล้มทั้งงาน
- ปุ่ม "ลองต่อจากขั้นนี้" ทำต่อจากขั้นที่ล้มโดยเก็บบทและเสียงเดิม
- ทดสอบ Rust ผ่าน 32 ข้อ (`cd app && cargo test`)
